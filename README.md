# 📚 QuizFlash - Application de Fiches

QuizFlash est une application web de fiches de révision développée dans le cadre de mon stage en développement d'applications chez CodeAlpha.

L'application permet de créer, consulter, modifier et supprimer des fiches de révision de manière simple et interactive.

## ✨ Fonctionnalités

- 📖 Affichage des questions
- 👁️ Affichage et masquage des réponses
- ⬅️ Navigation vers la fiche précédente
- ➡️ Navigation vers la fiche suivante
- ➕ Ajout de nouvelles fiches
- ✏️ Modification des fiches
- 🗑️ Suppression des fiches
- 💾 Sauvegarde des fiches avec LocalStorage
- 📊 Barre de progression
- 🔔 Notifications utilisateur
- ✨ Animations de l'interface
- 📱 Interface responsive

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- LocalStorage
